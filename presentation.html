MCP Reminders Server

AI-Powered Reminder Assistant using Model Context Protocol

Seamless Task Management Through Natural Conversation

Problem Statement

Current Challenges

  • Context Switching: Users must leave their current workflow to open separate reminder apps
  • Manual Interaction: Traditional apps require navigating menus and filling forms
  • Forgotten Tasks: The friction of creating reminders leads to missed tasks
  • Disconnected Experience: AI assistants can't interact with task management tools

The Gap

There's no seamless way to manage reminders through natural language conversation with AI assistants.

Our Solution

An MCP-based Reminder Server that integrates directly with AI assistants like Claude Desktop.

Natural Language

"Remind me in 2 hours"

No App Switching

Stay in your AI chat

Full CRUD

Create, List, Complete, Delete

Persistent Storage

Reminders saved locally

Due Alerts

Check overdue reminders

Flexible Time

Relative & absolute formats

Key Components

  • MCP Server: Exposes tools via Model Context Protocol
  • Time Parser: Handles "in 30 minutes" and "2024-12-15 14:00" formats
  • JSON Storage: Persistent local file storage

MCP Tools Implemented

create_reminder

Create a new reminder with message and time

@mcp.tool
def create_reminder(message, time)

list_reminders

List all reminders by status (pending/completed/all)

get_due_reminders

Get all overdue reminders

complete_reminder

Mark a reminder as completed

delete_reminder

Permanently delete a reminder

Supported Time Formats

  • "in 30 minutes"
  • "in 2 hours"
  • "in 1 day"
  • "2024-12-15 14:00"

Technology Stack

Python 3.10+ FastMCP Model Context Protocol Claude Desktop uv JSON

Why These Technologies?

  • FastMCP: Simplest way to build MCP servers with Python decorators
  • MCP Protocol: Industry standard for AI tool integration (by Anthropic)
  • uv: Lightning-fast Python package management
  • JSON: Human-readable, portable data storage
